# my-skills

This repo consists of skills i have been using everyday like .md files.

## Skills

### [deck-craft](deck-craft/SKILL.md)

A design and process layer on top of Anthropic's built-in `pptx` skill for making PowerPoint (`.pptx`) decks that don't look AI-generated.

- Skill: [deck-craft/SKILL.md](deck-craft/SKILL.md)
- Docs: [deck-craft/README.md](deck-craft/README.md)

### [material-you-kit](material-you-kit/SKILL.md)

A skill for building interfaces with Google's Material Design 3 (M3) across React/MUI, web, Flutter, and Jetpack Compose.

- Skill: [material-you-kit/SKILL.md](material-you-kit/SKILL.md)

## Install

### From source (Claude Code)

```bash
git clone https://github.com/charansaiponnada/my-skills ~/.claude/skills/deck-craft
```

Restart the session. The skill name must match the folder name.

### With the Agent Skills CLI (`npx`)

```bash
npx skills add charansaiponnada/my-skills@deck-craft -g -y
npx skills add charansaiponnada/my-skills@material-you-kit -g -y
```
